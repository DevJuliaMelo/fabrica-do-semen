# Fábrica do Sêmen

Jogo educativo para aprender as **glândulas acessórias masculinas**: vesículas seminais, próstata e glândulas bulbouretrais.

O mascote Nado, um espermatozoide, guia o jogador por 5 fases:

1. **A história:** os personagens da fábrica, o mapa do corpo e um quiz com perguntas sorteadas.
2. **Monte o caminho:** coloque as glândulas na ordem em que o sêmen passa por elas.
3. **Chuva de ingredientes:** pegue só os ingredientes de cada glândula.
4. **Laboratório:** acerte a receita do sêmen e deixe os 6 medidores verdes.
5. **Missão detetive:** descubra qual glândula faltou em cada amostra.

No final, o jogador recebe um diploma com o próprio nome.

## Como jogar

Abra o link do GitHub Pages ou o arquivo `index.html` no navegador. Funciona no celular e no computador, sem instalar nada.

O progresso fica salvo no próprio navegador de cada jogador.

## Observações

- As ilustrações são esquemas didáticos simplificados, não ilustrações médicas exatas.
- O pH do laboratório é um modelo simplificado. O volume mínimo (1,4 mL) e o pH de referência (≥ 7,2) seguem o manual da OMS (2021).
- O ranking ao vivo da turma só existe na versão hospedada no claude.ai. Nesta versão, o botão de ranking fica escondido.
